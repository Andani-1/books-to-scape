# Book Market Analytics

This project uses Python to collect and analyse book data from Books to Scrape. It examines the prices of books, their ratings, stock availability and genres, and then looks for patterns in graphs and using machine learning.

## Main Objectives
- Scrape books details from the web.
- Organise and clean the data set.
- Examine pricing, ratings and genres.
- Make graphs to illustrate trends in the data.
- Investigate whether book ratings can be used to predict book prices, using linear regression.

  ## Tools Used
  - Python
  - Pycharm
  - Jupyter Notebook
  - Pandas
  - Matplotlib
  - Seaborn
  - Scikit-learn
  - Requests
  - Beautiful Soup
 
  ## Dataset
    There are 1,000 book records in the first data set, with the following information:
  - The price of the books will be in GBP and the titles will be in English.
  - Ratings and genres.
  - Stock information.
  - Descriptions and product URLs.
